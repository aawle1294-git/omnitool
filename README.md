# ⚡ AllDesk (Notion Edition & 설치 마법사)

AllDesk는 **모던한 노션(Notion) UI/UX**와 **익숙한 윈도우 설치 마법사(Setup Wizard)** 방식을 결합한 올인원 데스크 웹 애플리케이션입니다.  
**100% 브라우저 로컬(Client-side) 처리** 방식으로 동작하므로, 사용자의 파일(사진, PDF, 텍스트)이 외부 서버로 전혀 전송되지 않아 완벽한 보안과 프라이버시를 보장합니다.

---

## 🌟 주요 기능 & UI 안내

### 1. 📦 노션 인스톨러 (프로그램 설치 마법사)
우리에게 가장 익숙한 **소프트웨어 설치 마법사(Setup Wizard)** 단계로 구성되어 누구나 쉽게 프로그램을 일괄 설치할 수 있습니다:
* **단계별 설치 마법사 (5단계 구성)**:
  1. **환영 및 라이선스 (Welcome)**: 설치 안내 및 원클릭 추천 팩(새 PC 필수팩, 개발자 스타터팩, 미디어팩)
  2. **구성 요소 선택 (Select Components)**: 카테고리별 트리 체크박스, 필요 용량 자동 계산
  3. **설치 옵션 (Options)**: 무인 자동 설치(`--silent`), 라이선스 자동 승인 옵션
  4. **설치 진행 (Installing)**: 실시간 프로그레스 바 & 터미널 콘솔 로그 시각화
  5. **설치 완료 (Completed)**: 자동 설치 배치파일(`.bat`), PowerShell 원클릭 스크립트 제공
* **다양한 뷰 모드 지원**:
  * 🪄 **설치 마법사 모드 (Setup Wizard)**
  * 🖼️ **갤러리 뷰 (Notion Gallery Cards)**
  * 📊 **데이터베이스 테이블 뷰 (Notion Database Table)**

---

### 2. 📉 파일 용량 압축기 (File Compressor)
* **이미지 압축 (PNG, JPG, WEBP)**
  * 품질 조절 슬라이더, 해상도 리사이즈, 용량 60~85% 절감, 다중 일괄 압축 & ZIP 다운로드
* **PDF 용량 압축 (PDF Compressor)**
  * 대용량 PDF 문서 최적화 (최대 압축 / 균형 / 고화질 유지 프리셋)

---

### 3. 🔄 파일 형식 변환기 (Format Converter)
* **PDF ➔ 고해상도 이미지 변환**: 모든 페이지 PNG/JPG 추출 및 개별/ZIP 다운로드
* **이미지 ➔ PDF 병합**: 여러 사진을 표준 A4 규격 단일 PDF로 정돈 병합
* **이미지 포맷 변환**: PNG ⬌ JPG ⬌ WEBP 즉시 변환
* **PDF 병합 및 분할**: 여러 PDF 파일 합치기 및 특정 페이지만 추출

---

### 4. 🛠️ 스마트 생산성 도구함 (Extra Productivity Tools)
* **QR 코드 스튜디오**: 웹 링크, 와이파이 자동 연결 QR(SSID/비번), 색상 커스텀, PNG 다운로드
* **강력한 비밀번호 생성기**: 엔트로피 기반 실시간 보안 강도 판별 및 원클릭 복사
* **텍스트 & JSON 도구**: 글자수/단어수/바이트 계산, 케이스 변환(camelCase, snake_case), JSON 정렬/압축, Base64 변환
* **데이터 단위 계산기**: Bytes, KB, MB, GB, TB 상호 환산
* **로컬 자동 저장 메모장 & 투두**: 브라우저 로컬 저장소(`localStorage`)에 실시간 자동 보존
